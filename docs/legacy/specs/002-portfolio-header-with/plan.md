## Summary
Responsive portfolio header component with SVG logo branding and navigation menu. Provides "ABOUT" navigation link with desktop horizontal layout and mobile hamburger menu with full-screen overlay. Integrates with existing masonry gallery without interference, using global design system styles.

## Technical Context
**Language/Version**: TypeScript 5.0+ targeting ES2020
**Primary Dependencies**: Vite (build), Vitest (testing), no external UI frameworks
**Storage**: Static SVG assets for responsive logos, no database needed
**Testing**: Vitest with jsdom for DOM testing
**Target Platform**: Modern browsers (Chrome 90+, Firefox 88+, Safari 14+)
**Project Type**: Single frontend project (existing structure with src/, tests/)
**Performance Goals**: <100ms header interaction, smooth 60fps animations
**Constraints**: Must not interfere with existing masonry gallery, integrate with global styles
**Scale/Scope**: Single header component, ~5-10 navigation items potential, responsive design
